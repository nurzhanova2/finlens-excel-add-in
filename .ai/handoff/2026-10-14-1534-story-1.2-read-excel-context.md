# Story 1.2 — read Excel context

## Что сделано

- Реализованы переключение scope кнопками и slash-командами `/range`, `/sheet`, `/workbook`, а также видимая context badge.
- Добавлен изолированный Office.js read-only extractor: `range` читает только выбранный диапазон; `sheet` — только used range активного листа; `workbook` строит только metadata-карту листов.
- `TabularArtifact` содержит values, formulas, number formats, имя листа и A1-address. До загрузки cell payload проверяются пустота и лимит в 10 000 ячеек.
- Добавлены тесты extractor, scope selection и неизменности workbook. Write Office.js API отсутствуют.

## Принятые решения

- Extractor использует стабильный ExcelApi 1.1 (`getSelectedRange`, `getUsedRangeOrNullObject`, read-only `load` и `sync`), поэтому manifest и runtime compatibility check остаются на `ExcelApi 1.1`.
- Лимит ограничивает payload до чтения values/formulas/formats; карта книги не включает ячейки.
- Ошибки пустого, недоступного или oversized scope блокируют отправку и дают одно следующее действие.
