# Story 1.1 — task pane scaffold

## Что сделано

- Создан React/TypeScript task pane FinLens и Office manifest для Excel Workbook.
- Панель показывает заголовок, пустую область диалога и поле вопроса.
- Добавлена runtime-проверка `ExcelApi 1.1`; при несовместимости показано текстовое сообщение, а ввод и отправка вопроса отключены.
- Добавлены видимый keyboard focus, текстовые label, логичный DOM/Tab-порядок и `aria-live` для статуса.
- Office-адаптер ограничен capability discovery и не обращается к workbook.
- Добавлены тесты compatibility, accessibility UI и неизменности тестовой workbook fixture.

## Изменённые файлы

- `package.json`, `package-lock.json`, `tsconfig.json`, `vite.config.ts`, `eslint.config.js`, `index.html`
- `manifest.xml`
- `src/main.tsx`, `src/taskpane/App.tsx`, `src/taskpane/office.ts`, `src/taskpane/styles.css`
- `src/taskpane/*.test.*`, `src/test/setup.ts`

## Принятые решения

- Для реализованного начального экрана объявлен и проверяется `ExcelApi 1.1`: эта версия достаточна для текущей capability check; минимум для extractor будет пересмотрен в Story 1.2, как требует Architecture Spine.
- В manifest остаётся `ReadWriteDocument`, так как его требует application-specific Excel API даже для чтения; код не содержит write Office.js API.
- Отправка вопроса пока выводит локальное status-сообщение и не вызывает API/Excel: анализ и контекст не входят в Story 1.1.

## Команды и проверки

- `npm test` — успешно: 3 файла, 5 тестов.
- `npm run typecheck` — успешно.
- `npm run lint` — не завершился: файл ESLint в `node_modules` синтаксически повреждён после прерванной параллельной установки npm, не ошибка исходников.
- `npm run build`, XML validation и статический scan write API ещё не выполнены из-за остановки цепочки на lint.

## Что осталось сделать

- Восстановить generated dependencies из `package-lock.json`.
- Повторить lint, build, XML validation и статический scan read-only ограничения.

## Риски и блокеры

- Нужна ручная sideload-проверка manifest в Excel Desktop на Windows: она не может быть выполнена в текущей macOS-среде.
