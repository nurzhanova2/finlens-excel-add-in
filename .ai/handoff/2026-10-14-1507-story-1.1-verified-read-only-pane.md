# Story 1.1 — verified read-only pane

## Что сделано

- Завершена Story 1.1: создана одна task pane FinLens для Excel Workbook с заголовком, пустой областью диалога и полем вопроса.
- Реализована runtime-проверка `ExcelApi 1.1`; несовместимый host получает понятную ошибку, а поле и отправка вопроса отключены.
- UI не показывает login, экспорт или команды изменения Excel.
- Добавлены доступные текстовые label, `aria-live`, role alert, видимый focus и последовательный порядок интерактивных элементов.
- Office-слой содержит только `isSetSupported`; write Office.js API отсутствуют.
- Автоматический тест теперь монтирует task pane и подтверждает неизменность тестовой workbook fixture до/после открытия панели.
- Добавлен `.gitignore` для generated `node_modules`, `dist` и `coverage`.

## Принятые решения

- Текущий manifest и runtime check используют `ExcelApi 1.1`; это минимальный requirement текущего экрана, который не извлекает данные. Requirement для extractor остаётся предметом Story 1.2 согласно Architecture Spine.
- `ReadWriteDocument` сохранён в manifest по NFR-04: application-specific Excel API требует его даже при функционально read-only реализации. Код не использует write API.
- Нажатие «Отправить вопрос» не запускает анализ и не обращается к Excel/API: показывает локальный статус до реализации следующих историй.
