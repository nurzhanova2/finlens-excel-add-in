# Story 1.3 — free question API

## Что сделано

- Реализован typed FastAPI endpoint `POST /api/analysis` с валидацией request, bounded `TabularArtifact` и typed completed/failed result.
- Добавлен server-side Qwen port: production adapter использует OpenAI-compatible endpoint и получает только ограниченный artifact; `FINLENS_QWEN_PROVIDER=fake` включает явный детерминированный тестовый provider. Реальные credentials читаются только на server из `FINLENS_QWEN_*` environment variables.
- Task pane отправляет свободный вопрос только для `range`/`sheet`, показывает этапы «Читаю выбранные данные…» и «Готовлю вывод…», блокирует параллельную отправку, рендерит conclusion/evidence/risks/assumptions/next check и фактические sources.
- API не логирует ячейки, question или prompt: только `analysisId`, elapsed time и error code. Fake-provider test подтверждает простой ответ существенно быстрее одной минуты.
- Обновлён sprint tracker: Epic 1 `in-progress`, Stories 1.2 и 1.3 `review` после успешных проверок.

## Принятые решения

- Story 1.3 намеренно принимает только `range` и `sheet`; `workbook` остаётся картой metadata до Story 1.4.
- При отсутствии Qwen configuration backend возвращает честный `QWEN_NOT_CONFIGURED`, а не маскирует fake provider под production.
- Максимум artifact — 10 000 ячеек; schema проверяет размер и одинаковую форму values/formulas/numberFormats.
- Нет Python sandbox, retry-логики, графиков или Excel write API.

## Известные ограничения и блокеры

- Внутренний Qwen endpoint и его server environment не предоставлены, поэтому production provider не был вызван; fake provider используется только в тестовом режиме.
- Реальная sideload-проверка в Excel Desktop на Windows недоступна в текущей macOS-среде.
- Выполнен только тестовый latency fake-provider; end-to-end замер внутреннего Qwen требуется после выдачи endpoint.
