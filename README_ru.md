> [!IMPORTANT]
> FinLens никогда не изменяет книгу. Он читает только выбранный вами контекст, передаёт его через
> FinLens API во внутреннюю модель Qwen и показывает ответ в панели. В книгу ничего не вставляется,
> после сеанса ничего не хранится.

## Зачем этот проект

Финансовый аналитик тратит много времени, чтобы разобраться в незнакомой модели: где драйверы,
почему изменилась строка, сходятся ли итоги, какие допущения выглядят агрессивно. FinLens позволяет
задать эти вопросы обычным языком прямо рядом с данными:

```text
выбрать контекст → прочитать данные (только чтение) → задать вопрос → рассуждение модели → Python-расчёт при необходимости → проверяемый ответ
```

Каждый ответ показывает источники — точные листы и диапазоны. Если нужен расчёт, FinLens выполняет
Python-код в изолированной песочнице и показывает именно этот код, таблицы результатов и график:
аналитик проверяет числа, а не верит пересказу.

## Что умеет

| Возможность | Подробности |
|---|---|
| Выбор контекста | Выделенный диапазон, активный лист или вся книга; плашка показывает, что именно будет прочитано |
| Вопрос своими словами | На русском или английском; ответ приходит на языке вопроса |
| Ответ как у аналитика | Вывод, доказательства, риски и допущения, следующая проверка, источники, ID анализа |
| Большие книги | Сначала карта книги, затем чтение только релевантных диапазонов — и ответ прямо об этом говорит |
| Расчёты | `pandas` / `numpy` / `matplotlib` в одноразовом контейнере; до 2 автоматических исправлений |
| Проверяемый результат | Методика, таблицы, выполненный код, PNG-графики с метрикой, периодом и ключевым выводом |
| Уточняющие вопросы | Диалог помнит контекст, пока открыта панель |
| Прогресс и отмена | Этап описан словами; отмена останавливает запрос к модели и расчёт в песочнице |
| Честные ограничения | Ответ «данных недостаточно» и понятные ошибки с одним следующим шагом |
| Доступность | Полное управление с клавиатуры, озвучивание для экранного диктора, смысл не передаётся только цветом |

## Главное правило

> [!WARNING]
> Модель может ошибаться. Вывод надёжен настолько, насколько надёжны данные и расчёт за ним.
> Прежде чем использовать результат в решении, проверьте источники, методику и выполненный код.

Часть проверки FinLens делает сам: расчётное утверждение показывается только при успешно выполненном
расчёте; после трёх неудачных попыток вместо ответа — честная ошибка, а не угаданное число.

## Панель

```text
┌──────────────────────────────────────────────┐
│ FinLens                                      │  заголовок
│ Read-only аналитик для Excel                 │  обещание read-only
│ [Выделение · P&L · A1:F40]                   │  плашка контекста
│ (Выделение) (Лист) (Книга)                   │  выбор контекста
├──────────────────────────────────────────────┤
│ Вопрос 1 · Выделение: Почему упала маржа?    │  история диалога
│   Вывод / Доказательства / Риски и допущения │  ответ
│   Следующая проверка / Источники / ID        │
│   ▸ Методика ▸ Таблицы ▸ Код ▾ График [PNG]  │  проверяемый расчёт
│ (Начать новый диалог)                        │
├──────────────────────────────────────────────┤
│ Уточняющий вопрос                            │  поле вопроса
│ (Отправить вопрос)  (Отменить анализ)        │
│ Этап: Готовлю вывод…   Анализ идёт 12 с.     │  этап и время
└──────────────────────────────────────────────┘
```

| Элемент | Что делает |
|---|---|
| «Выделение» / «Лист» / «Книга» | Диапазон / активный лист / вся книга. Смена контекста начинает новый диалог |
| Плашка контекста | Например, `Выделение · P&L · A1:F40` или `Книга · 6 лист(ов), с данными: 4` |
| Диалог | «Вопрос N · контекст» и ответ; уточняющие вопросы учитывают предыдущие ходы |
| «Источники» | Точные строки `лист · диапазон`; «Копировать источники» копирует их |
| «Данных недостаточно…» | Если данные не позволяют сделать вывод: список недостающего, заголовок «Вывод (не подтверждён)» |
| Покрытие книги | «Проанализирована только часть книги… Это не анализ всей книги» и перечень диапазонов |
| «Методика» / «Таблицы» / «Код» | Метод и входные данные, таблицы результата, фактически выполненный код; «Копировать код» |
| «График» | PNG с метрикой, периодом и ключевым выводом; клик или Enter — увеличить, Esc — закрыть |
| «Этап: …» | Текущий этап словами; спиннера нет, цвет только дублирует текст |
| «Отменить анализ» | Появляется и получает фокус во время анализа; Esc делает то же |

Перейти к диапазону-источнику из панели нельзя: выделение ячеек изменило бы состояние книги, что
запрещено правилом read-only. Найдите диапазон по точному тексту источника.

## Быстрый старт для аналитика

1. Откройте книгу в Excel Desktop → «Главная» → **«Открыть FinLens»**.
2. Выделите диапазон или нажмите «Лист» либо «Книга». Проверьте плашку контекста.
3. Введите вопрос и нажмите **Enter**.
4. Раскройте «Методика», «Таблицы» или «Код», чтобы проверить числа; при необходимости задайте уточняющий вопрос.

| Клавиша / команда | Действие |
|---|---|
| Enter | Отправить вопрос |
| Shift+Enter | Новая строка |
| Tab / Shift+Tab | Кнопки контекста → результаты → новый диалог → панель ошибки → вопрос → отправить → отменить |
| Esc | Отменить идущий анализ (или сначала закрыть увеличенный график) |
| `/range`, `/sheet`, `/workbook` + Enter | Сменить контекст и начать новый диалог |

**Хороший вопрос** называет показатель, период и, если известно, строки: *«Сравни выручку 2024 и 2025
по сегментам и объясни главные причины»*. Если нужны точные цифры, явно попросите расчёт; выбирайте
наименьший контекст, в котором есть ответ.

| Русский | English |
|---|---|
| Почему операционная прибыль снизилась, хотя выручка выросла? | What changed between 2024 and 2025, and which lines drove the change? |
| Посчитай рост выручки год к году по сегментам и построй график. | Calculate the gross margin for each quarter and plot it. |
| Какие статьи затрат требуют проверки в первую очередь? | Which forecast assumptions look aggressive compared with actuals? |
| Найди листы с бюджетом и фактом и сравни их. *(«Книга»)* | Are there rows where totals do not equal the sum of components? |

## Статусы и ошибки

| Этап | Текст в панели | Что происходит |
|---|---|---|
| `reading_context` | «Читаю выбранные данные…» | Чтение выбранных данных из Excel |
| `mapping_workbook` | «Строю карту книги…» | Список листов и их размеров, без значений ячеек |
| `selecting_artifacts` | «Выбираю релевантные листы и диапазоны…» | Модель выбирает до 5 релевантных диапазонов |
| `preparing_answer` | «Готовлю вывод…» | Модель готовит ответ |
| `running_computation` | «Выполняю расчёт в изолированной песочнице…» | Python выполняется в песочнице |
| `retrying_computation` | «Исправляю расчёт (попытка N из 2)…» | Автоматическое исправление после ошибки |
| `finalizing` | «Завершаю ответ…» | Ход записывается в диалог |
| `cancelling` / `cancelled` | «Отменяю анализ…» / «Анализ отменён» | Остановлено и очищено; задайте новый вопрос |
| `completed` | «Готово: ответ получен за N с.» | Ответ показан |

Ошибка показывается одной панелью: что произошло, «Следующий шаг» и не больше одной кнопки —
«Повторить», «Выбрать другой контекст» или «Изменить вопрос».

| Код | Что произошло | Что делать |
|---|---|---|
| `EMPTY_CONTEXT`, `CONTEXT_UNAVAILABLE` | В контексте нет данных или Excel их не отдал | Выделите диапазон с данными / откройте книгу заново |
| `CONTEXT_TOO_LARGE`, `WORKBOOK_TOO_LARGE`, `WORKBOOK_SCOPE_TOO_LARGE` | Больше 10 000 ячеек, 100 листов или 5 диапазонов / 20 000 ячеек | Сузьте контекст |
| `NO_RELEVANT_DATA`, `WORKBOOK_MAP_MISSING` | Релевантные данные не найдены / карта книги устарела | «Лист» на нужном листе / выберите «Книга» заново |
| `QUESTION_EMPTY`, `QUESTION_TOO_LONG` | Нет вопроса / больше 4 000 символов | Измените вопрос |
| `QWEN_INVALID_RESPONSE`, `UNVERIFIED_COMPUTATION` | Ответ модели непригоден / утверждение без успешного расчёта | Переформулируйте; уточните, какой расчёт нужен |
| `COMPUTATION_FAILED` | 3 неудачные попытки расчёта; ответ не выдумывается | Сузьте данные или переформулируйте |
| `QWEN_UNAVAILABLE`, `SANDBOX_BUSY`, `ANALYSIS_CAPACITY`, `SESSION_CAPACITY` | Сервис занят или не отвечает | Повторите через минуту |
| `ANALYSIS_TIMEOUT` | Анализ превысил лимит времени | Выберите меньше данных и повторите |
| `NETWORK_UNAVAILABLE`, `API_UNAVAILABLE`, `STATUS_UNAVAILABLE`, `CANCEL_UNCONFIRMED` | Потеряна связь с FinLens API | Проверьте корпоративную сеть и повторите |
| `SESSION_NOT_FOUND`, `SESSION_SCOPE_MISMATCH`, `PLAN_NOT_FOUND`, `ARTIFACTS_MISMATCH`, `ANALYSIS_NOT_FOUND`, `ANALYSIS_CONFLICT`, `INTERNAL_ERROR` | Сеанс истёк или состояние устарело | Отправьте вопрос ещё раз |
| `UNSUPPORTED_EXCEL` | Excel не поддерживает ExcelApi 1.1 | Используйте или обновите Excel Desktop для Windows |
| `QWEN_NOT_CONFIGURED`, `SANDBOX_UNAVAILABLE` | FinLens не настроен или песочница недоступна | Сообщите администратору FinLens |

Тексты ошибок никогда не содержат traceback, путей, ключей и сырых исключений Excel или сети.

## Границы продукта

- **Excel никогда не редактируется** — ни ячейки, ни формулы, ни форматы, ни листы, ни имена, ни выделение.
- **В книгу ничего не вставляется** — графики, таблицы и расчёты остаются в панели.
- **Нет экспорта, входа и сохранённой истории** — диалог живёт, пока открыта панель (TTL сеанса на сервере по умолчанию 30 мин).
- **Нет внешних данных** — ни рыночных, ни макроэкономических, ни интернет-данных; у песочницы нет сети.
- **Режим «Книга» избирателен** — не больше 5 диапазонов и 20 000 ячеек на ответ, и ответ прямо об этом пишет.
- **Лимиты** — 10 000 ячеек на диапазон или лист, 100 листов, 4 000 символов в вопросе, 3 попытки расчёта.

## Безопасность и приватность

| Вопрос | Ответ |
|---|---|
| Что покидает Excel? | Только выбранный контекст: копии значений, формул и числовых форматов. В режиме «Книга» сначала только имена и размеры листов, затем только выбранные диапазоны |
| Куда уходит? | Во внутренний FinLens API и во внутреннюю модель Qwen. Больше никуда |
| Что хранится? | Ничего. Диалог, карта книги, код, таблицы и графики удаляются при новом диалоге, смене контекста, закрытии панели, отмене или истечении сеанса |
| Как выполняется код модели? | В одноразовом контейнере: без сети, без файлов и секретов сервера, без доступа к Excel, не от root, файловая система только для чтения, лимиты CPU, памяти и времени. Код проверяется до запуска; без песочницы ничего не выполняется |
| Что делает отмена? | Закрывает запрос к модели, удаляет работающий контейнер и отбрасывает частичный результат |
| Что пишется в логи? | Только технические метаданные: ID анализа, коды, длительности, размеры |
| Где учётные данные? | Ключ Qwen есть только на сервере. В надстройке нет секретов и входа; доступ ограничен корпоративной сетью |

Office требует разрешение `ReadWriteDocument` даже для чтения книги. Гарантия read-only обеспечивается
кодом: API записи Office.js не используется, статические проверки это запрещают, а приёмочный тест
сравнивает хэш файла до и после сеанса.

## Как устроено

```text
Excel (Office.js, только чтение)
   │  копия контекста
   ▼
Панель (React)  ──  один HTTPS-origin  ──▶  FinLens API (FastAPI)
                                              ├── адаптер Qwen ──▶ внутренний Qwen (OpenAI-совместимый)
                                              └── запуск песочницы ─▶ docker run finlens-sandbox:1
                                                                       (--network none, --read-only,
                                                                        не root, лимиты ресурсов)
```

API проверяет каждый запрос, каждый вызов инструмента моделью и каждый результат песочницы. Анализ
выполняется асинхронно: панель опрашивает `GET /api/analyses/{id}` и отменяет через
`POST /api/analyses/{id}/cancel`.

## Локальный запуск

Нужны Node.js 20.19+ или 22.12+, Python 3.11, Docker и — для настоящей надстройки — Excel Desktop для Windows.

```bash
npm ci
python3 -m pip install -r api/requirements.txt
npm run dev:certs        # один раз: доверенный localhost-сертификат для надстроек Office
npm run sandbox:build    # собирает finlens-sandbox:1 (Docker должен быть запущен)

npm run dev:api          # терминал 1: API на 127.0.0.1:8000
npm run dev              # терминал 2: панель на https://localhost:5173, /api проксируется на API
```

Sideload в Excel Desktop: `npx office-addin-debugging start manifest.xml desktop` или каталог
надстроек в общей папке с `manifest.xml`. На Windows без `python3` API запускается так:
`py -m uvicorn app.main:app --app-dir api --host 127.0.0.1 --port 8000`.

**Тестовый провайдер.** `FINLENS_QWEN_PROVIDER=fake` включает детерминированную замену Qwen, которая
ничего не анализирует. Маркеры в вопросе включают сценарии: `[fake:compute]`, `[fake:retry]`,
`[fake:invalid-tool]`, `[fake:fail]`, `[fake:unverified]`, `[fake:slow]`, `[fake:long]`, `[fake:insufficient]`.

**Production Qwen** — задаётся только на сервере из хранилища секретов; не коммитьте эти значения и не
кладите их в manifest или панель:

| Переменная | Назначение |
|---|---|
| `FINLENS_QWEN_BASE_URL` | OpenAI-совместимый base URL, например `https://<внутренний-хост-qwen>/v1` |
| `FINLENS_QWEN_API_KEY` | Серверный ключ |
| `FINLENS_QWEN_MODEL` | Имя модели (по умолчанию `qwen`) |
| `FINLENS_QWEN_PROVIDER` | В production не задавать |

| Автотесты (панель, API, реальная Docker-песочница) | проходят на macOS с Docker Desktop и тестовым провайдером |
| Excel Desktop для Windows | ожидает ручной приёмки |
| Production Qwen (качество, время, отмена на реальном endpoint) | ожидает |

Пошаговые проверки: [чек-лист ручной приёмки](docs/acceptance/manual-acceptance.md).

## Известные ограничения

- **Один процесс API.** Сеансы и идущие анализы живут в памяти одного процесса. Запускайте один
  процесс или направляйте каждую панель в один и тот же; перезапуск очищает все диалоги. См.
  [чек-лист production-развёртывания](docs/deployment/production-checklist.md).
- **Целевая платформа** — Excel Desktop для Windows с ExcelApi 1.1; Excel в браузере и на Mac — нет.
- **Нет перехода к диапазону-источнику** — это изменило бы выделение.
- **Прогресс опрашивается** каждые 0,5 с, без streaming.
- Отмена, пришедшая после фиксации ответа, отклоняется; ответ показывается с пометкой.
- Лимиты — стартовые значения; их нужно уточнить на реальных обезличенных книгах.
