# FinLens — Design Spine

## Brand & Style

FinLens — спокойный, плотный профессиональный инструмент внутри Excel. Панель не конкурирует с таблицей и не пытается выглядеть как отдельный потребительский продукт: приоритет — понятность анализа, источников и расчётов. 

**[ASSUMPTION]** Базовый визуальный язык наследует знакомые нейтральные паттерны Office: светлый фон, сдержанный синий для основного действия, тонкие разделители и минимум декоративных элементов. Это решение можно заменить корпоративной дизайн-системой без изменения EXPERIENCE.md.

## Colors

- **Surface** — нейтральная светлая поверхность панели; не соперничает с таблицей Excel.
- **Primary** — сдержанный синий только для отправки вопроса, активного контекста и доступных ссылок.
- **Text** — высокий контраст для чисел, объяснений и кода.
- **Success / warning / error** — используются для факта выполнения, ограничений и ошибок, а не для оценки финансовых результатов.
- Не использовать градиенты, «праздничные» иллюстрации, декоративные карточки или цветовое кодирование финансовых выводов без текстового пояснения.

## Typography

**[ASSUMPTION]** Используется системный шрифт Windows / Office UI. Числа, адреса диапазонов и код — моноширинный стиль только там, где различимость символов важнее общего текста.

- Заголовки ответа короткие и информативные.
- Основной аналитический вывод читается как документ: абзацы, списки и таблицы.
- Листы, диапазоны и Python-код сохраняют точное написание и не сокращаются без возможности раскрыть полный текст.

## Layout & Spacing

Панель — одна вертикальная колонка. Сверху вниз: заголовок и активный контекст, история диалога, поле вопроса. Детали результата раскрываются внутри сообщения, а не открывают вложенные окна.

**[ASSUMPTION]** Базовый интервал — 8 px: 8/12 px внутри компактных блоков, 16 px между сообщениями, 24 px между крупными смысловыми частями ответа. Плотность достаточна для аналитической работы, но текст не сливается в стену.

## Elevation & Depth

Иерархия строится разделителями, типографикой и отступами. Тень допустима только для всплывающего списка контекста или просмотра PNG; не использовать её для каждого сообщения или блока расчёта.

## Shapes

**[ASSUMPTION]** Небольшое скругление (4–6 px) для поля вопроса, кнопок и раскрываемых блоков. Не использовать крупные радиусы и pill-формы: FinLens — рабочий инструмент, не мессенджер.

## Components

- **Контекстная плашка** — показывает один активный scope: `Выделение`, `Лист` или `Книга`, плюс точный адрес/имя. Визуально заметна, но не выглядит как предупреждение.
- **Сообщение аналитика** — содержит вывод, источники и, при необходимости, раскрываемые «Методика», «Расчёты», «Код» и «График».
- **Источник данных** — текстовая ссылка на лист и адрес диапазона; не иконка без подписи.
- **Код** — моноширинный, только для фактически выполненной версии; копирование доступно одной явной кнопкой.
- **PNG-график** — отображается целиком в ширине панели; при недостаточной читаемости открывается в увеличенном просмотре.
- **Прогресс анализа** — короткая текстовая строка с текущим этапом, а не бесконечный спиннер.
- **Ошибка** — нейтральная, объясняет, что не удалось и что пользователь может сделать дальше.

## Do's and Don'ts

| Делать | Не делать |
|---|---|
| Показывать, какие данные и расчёты привели к выводу | Давать «чёрный ящик» без источников и кода |
| Использовать раскрываемые блоки для технических деталей | Выводить код и большие таблицы развёрнутыми по умолчанию |
| Подчёркивать неопределённость словами и источниками | Маскировать ошибку уверенным общим текстом |
| Сохранять визуальное первенство Excel-таблицы | Превращать task pane в отдельный dashboard |
| Давать заметную клавиатурную фокусировку | Полагаться только на hover и цвет |
