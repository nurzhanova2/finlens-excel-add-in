- (direction) Fast path выбран по запросу завершить планировочные артефакты; deliverable — architecture spine для реализации MVP.
- (decision) Парадигма: hexagonal backend с тонким Excel task pane adapter и однонаправленным job-потоком для аналитики; это разделяет Office.js, LLM и sandbox.
- (decision) Клиент — Excel Task Pane на React и TypeScript с Office.js; backend — FastAPI/Python; LLM — внутренний Qwen через OpenAI-compatible adapter; Python sandbox — ephemeral hardened Docker job.
- (decision) Нет пользовательской аутентификации. Внутренний backend не доверяет client input и использует только server-held credentials для Qwen; add-in не получает секреты.
- (decision) Read-only гарантия достигается запретом write Office.js API в коде и тестами неизменности workbook; manifest может технически требовать ReadWriteDocument для application-specific API.
- (decision) LLM вызывает ограниченный run_analysis tool через schema validation; server передаёт в sandbox только scoped tabular artifact и принимает максимум две code-fix попытки.
- (decision) Sandbox non-root, read-only root filesystem, no network, no host mounts/secrets, dropped Linux capabilities, package allowlist and resource/time/output limits.
- (decision) Данные, карта книги, код и результаты живут только в памяти/ephemeral storage одного сеанса и очищаются при закрытии или отмене; постоянной истории нет.
- (event) Артефакт утверждён пользователем и переведён в final.
